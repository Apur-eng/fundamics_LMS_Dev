# Coaching LMS

A common repository for cohesive development of the LMS app for coaching institutions and educators.

## Repository Structure

```
coaching-lms/
├── docs/                 # Project documentation
│   ├── requirements/     # Business and technical requirements
│   ├── architecture/     # System architecture and design diagrams
│   ├── database/         # Schemas, migrations, and ER diagrams
│   ├── security/         # Security guidelines and policies
│   ├── api/              # API specifications and contracts
│   └── decisions/        # Architecture Decision Records (ADRs)
├── frontend/             # Frontend client application
├── backend/              # Backend services and APIs
├── tests/                # End-to-end and integration test suites
├── .gitignore            # Git ignore rules
├── CONTRIBUTING.md       # Contribution guidelines
└── README.md             # Project overview
```
